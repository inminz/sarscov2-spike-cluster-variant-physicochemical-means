Mean physicochemical properties by cluster and WHO/Pango variant
How to read this figure. Each populated cell shows the mean physicochemical value for one WHO/Pango variant within one phenotypic cluster. Cell colour and the printed number represent the same mean value; each property uses its own colour scale. Blank cells indicate that no sequence from that variant was assigned to the corresponding cluster. Hover over any cell to display the property, variant, cluster, mean value, and number of contributing sequences.
